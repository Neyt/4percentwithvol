# Quantitative Finance Toolkit - Interactive Presentation

An interactive, modern web presentation showcasing three powerful quantitative finance libraries for algorithmic trading.

## 🎯 Overview

This presentation demonstrates three complementary libraries that form a complete quantitative trading toolkit:

1. **Strategy Automation** - Deploy and manage trading strategies with confidence
2. **Data Connectivity** - Seamless integration with market data sources
3. **Research Framework** - Backtest, analyze, and optimize trading strategies

## 🚀 Features

- **Interactive Navigation**: Use arrow keys, click buttons, or use the dot indicators to navigate
- **Beautiful Design**: Modern gradient backgrounds with smooth transitions
- **Responsive Layout**: Works on desktop and mobile devices
- **Code Examples**: Real Python code snippets for each library
- **Complete Workflow**: Shows how all three libraries work together

## 📦 Installation

```bash
cd quant-presentation
npm install
```

## 🎮 Running the Presentation

```bash
npm start
```

The presentation will open in your browser at `http://localhost:3000`

## 🎨 Technology Stack

- **React** with TypeScript
- **Tailwind CSS** for styling
- **Google Fonts** (Inter & JetBrains Mono)
- Modern CSS animations and transitions

## 📝 Customization

The presentation is built with React components, making it easy to customize:

- Edit slide content in `src/App.tsx`
- Modify colors in Tailwind classes
- Add new slides by extending the `slides` array
- Customize animations in `src/App.css`

## 🔧 Build for Production

```bash

```

This creates an optimized production build in the `build/` directory.
